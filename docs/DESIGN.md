# NoMark

An operating workspace for cleaning pasted text and documents. The user-approved
direction is cheerful pastel bento: cream ground, mint results, peach history,
rounded panels, and a task-first composition. ENERGY 2 / RHYTHM 2 / MOTION 1.

- Cream (#f7f5ef) keeps a long text session comfortable.
- Mint (#e1eee5) identifies the cleaned-output workspace; peach (#f3e4d8) identifies local history.
- Dark green (#244d3c) marks the primary action and provides readable contrast.
- System sans typography keeps Indonesian and English fast and familiar; generous
  headings add a friendly voice without requiring font downloads.
- Two equal workspaces support before/after comparison. The narrower history panel
  has a different tone because it is stored locally rather than processed on the server.
- Small file/document symbols describe actual controls. The selected wordmark is
  outlined in SVG so its letterforms remain consistent across operating systems.
  A compact "no" favicon preserves the same heavy lettering and green dot.
- The English sharing card uses the same Avenir Next typography, outlined logo,
  cream background, mint content panel, peach aside, and rounded geometry.
- Motion is limited to focus, hover, and process feedback; reduced motion is respected.
- Indonesian copy follows EYD V. Content findings never imply AI authorship.
- The service is public; the footer says "Open to everyone" rather than naming a personal tool.
- Theme defaults to the OS setting. A saved light/dark/system choice wins; the
  light pastel palette becomes dark forest/muted warm surfaces with readable ink.
- Processing-location labels describe a real privacy decision: local for text
  and non-PDF documents; an explicit permission control for server PDF uploads.
- Privacy and terms have English and Indonesian HTML pages and an actual contact.

- The Files workspace places four native radio choices (Documents, Images, Audio, Video) above the picker. The choices wrap to two columns on phones; each explains its scope before a file is selected. Mixed queues, processing routes, reports, and history retain the shared workflow.
