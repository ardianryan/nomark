# Alpha.7 exploratory model comparison

Status: **release gate not met**. These experiments do not replace the required three reviewed evaluation reports. The 40 new samples were fixed before generating candidate outputs. Raw outputs are synthetic and unreviewed; raw character differences are not a measure of useful or correct paraphrasing.

Both experiments ran in temporary non-root containers on CPU with two CPUs, a 2 GiB memory limit, no outbound network during inference, and no host ports. They did not alter production. Containers and the temporary model directory were removed. A single observed FLAN container memory reading was 570.7 MiB, not a measured peak. The candidate models were rejected on quality before an alpha.7 5,000-character capacity or cancellation test; the existing alpha.6 measurements do not establish those properties for a new candidate.

## OPUS-MT: exploratory relaxed filter

The existing pinned alpha.6 OPUS-MT models were tested with an experimental in-memory replacement of `acceptable_edit` that preserved numeric/URL/email tokens, capitalized words after the first, certain negation words, and an output-length range. The production pipeline was not changed. This deliberately incomplete filter is not a semantic-equivalence test.

Across 120 inputs, 53/60 Indonesian and 54/60 English outputs differed at the character level. These are raw counts, not validated useful rewrites. A clear critical error occurred for `id-01`: the instruction to use the original schedule became an instruction to reschedule. `en-02` changed one history book into history books. The sample from the user changed “Dunia remaja” into “Dunia Pemuda”. The candidate is rejected without treating the remaining unreviewed samples as safe. See `alpha7-opus-exploratory.json`.

## FLAN-T5 Base: two exploratory prompts

We tested the third-party CTranslate2 int8 conversion `jncraton/flan-t5-base-ct2-int8` at revision `baf426d609a303bf7dfb107d333c03c497557a29` with `model.bin` SHA-256 `d88af1c7429fcceec42f30e806182ed36081e9faadf19d9d7c5902e3f4596081`. This experimental artifact was downloaded into a temporary directory and removed; its provenance was not verified against a locally converted official model and it is not approved for distribution. The existing alpha.6 runtime's tokenizer and CTranslate2 decoded the model with beam size four and output cap 256. Inputs were synthetic; results were not run through the NoMark safety filter.

The first prompt used “Parafrasakan teks berikut dalam bahasa Indonesia tanpa mengubah makna:” for Indonesian and “Paraphrase the following text without changing its meaning:” for English. It changed 60/60 Indonesian and 11/60 English outputs at the character level. Several Indonesian outputs were incoherent; `id-03` replaced 12 books and 3 pencils with years. For `en-02`, the model omitted Jakarta. See `alpha7-flan-initial-exploratory.json`.

The second prompt used “Rewrite this Indonesian text with different words in Indonesian, preserving every detail:” and “Rewrite this text using different words while preserving every detail:”. It changed 48/60 Indonesian and 7/60 English outputs at the character level. For `id-01`, it omitted the instruction to use the original schedule. Both variants fail the no-critical-errors criterion, and their English change counts are below the 50% target even before judging whether changes are meaningful. See `alpha7-flan-alternative-exploratory.json`.

## Further local model experiments

On 2026-11-01, additional synthetic tests used an isolated CPU-only, read-only, non-root container limited to two CPUs and 2 GiB RAM with 128 MiB temporary storage and no external network during inference. The official `Qwen/Qwen2.5-1.5B-Instruct-GGUF` revision `91cad51170dc346986eccefdc2dd33a9da36ead9`, Q4_K_M SHA-256 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e`, was evaluated using the official llama.cpp b12032 CPU binary, archive SHA-256 `9f10432ca3f66ef003a7a540aaffb9da0acadaefd05404521b9ab7a2436af304`. Each sentence was rewritten separately; a preliminary rule checked URLs, email, numeric tokens, some capitalized words, negations, modal words and relative length. This experiment did not modify the shipped model or provide a semantic guarantee.

All 120 samples completed, with raw character differences in 48/60 Indonesian and 46/60 English results. Raw differences are not reviewed meaningful rewrites. Several outputs changed facts or instructions: “Mereka meminjam buku sejarah” became “Mereka mengambil buku sejarah”; memory became storage; and an instruction to keep original input disappeared. The user's sample was preserved unchanged by the preliminary rule. This candidate fails the quality gate. The raw, unreviewed output is in `alpha7-qwen-segmented.json`.

The official `Qwen/Qwen3-1.7B-GGUF` revision `90862c4b9d2787eaed51d12237eafdfe7c5f6077`, Q8_0 SHA-256 `061b54daade076b5d3362dac252678d17da8c68f07560be70818cace6590cb1a`, was screened on 12 samples with the same sentence approach. It also changed “meminjam” to “mengambil” and retained the user's input unchanged. It was rejected before a full evaluation. A self-check using that model accepted five out of five intentionally different Indonesian sentence pairs as equivalent when prompted in English, and accepted three of five with an Indonesian prompt. Self-check output is not reliable proof of meaning preservation. See `alpha7-qwen3-screen.json`, `alpha7-qwen3-verifier.json`, and `alpha7-qwen3-verifier-id.json`.

An exploratory third-party Q2_K conversion of `Qwen3-4B-Instruct-2507`, `unsloth/Qwen3-4B-Instruct-2507-GGUF` revision `a06e946bb6b655725eafa393f4a9745d460374c9` and SHA-256 `f7ed2f57713ad29e1a4ec093be0cdf3d7fd31e137e8fd4fc3edcfd04a5267862`, was screened on 12 samples in the same limits. It introduced the malformed phrase “dipertinjau sebelum diperluangkan” and retained the user's sample unchanged. Its conversion provenance was not validated for release. It was rejected; see `alpha7-qwen4b-screen.json`.

Two independent natural-language-inference checkers were screened against intentionally different and equivalent synthetic pairs. `MoritzLaurer/multilingual-MiniLMv2-L6-mnli-xnli` revision `0a71e92a985b6e1ad1828cf67ce9c459639c1dca` scored “meminjam” versus “mengambil” above 0.98 for entailment in both directions. `LazarusNLP/indobert-lite-base-p1-indonli-multilingual-nli-distil-mdeberta` revision `e5ec579b199655d7fc75c3b137292ac22d7434c9` was also applied to 120 Qwen2.5 outputs and 24 screening outputs. Among the 120 Qwen2.5 samples, a minimum bidirectional entailment threshold of 0.5 retained just 21/60 Indonesian and 26/60 English character changes and still accepted examples with lost or changed instructions. Lowering it to 0.4 retained 34/60 and 35/60 respectively, but accepted known critical changes. These scores are not meaningful-rewrite or quality assessments. See `alpha7-nli-screen.json`, `alpha7-indonli-screen.json`, and `alpha7-indonli-candidates.json`.

All experiment containers, the temporary CPU image pulled for the evaluation, and their temporary model directories were removed; existing production containers were not changed. No candidate was selected or integrated. A new model must pass all 120 independently reviewed examples and the capacity/cancellation tests before release.

## Additional 4 GiB staging screens

An experimental third-party Q4_K_M conversion of Qwen3.5-4B, revision `e87f176479d0855a907a41277aca2f8ee7a09523`, SHA-256 `00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4`, was screened with the 4 GiB staging limit. A memory snapshot was approximately 1.6–1.8 GiB, not a measured peak. It changed “borrowed” to “took” and “pertemuan” to “kegiatan”. Two self-check prompts still missed meaning changes. Twelve samples are insufficient for release evaluation; provenance, 5,000-character processing and cancellation remain unverified. See `alpha7-qwen35-screen.json`, `alpha7-qwen35-guard-screen.json`, and the two verifier reports.

The third-party quantized Cendol mT5 small instruction model, revision `e544357ac92cbea03fab341eb01e1853cf85cc4b`, SHA-256 `6fdc5179e4962b8394de456b2e44a183ef2acd71884ed0f72e691ae0dfc00397`, was screened using llama.cpp's encoder-capable example in an isolated, CPU-only staging container. On four examples it frequently repeated the input with a prefatory phrase, and translated the English example into Indonesian. This is an initial screen, not a 120-sample review or an evaluation of the original unquantized model. See `alpha7-cendol-native-screen.json`. The conversion's provenance has not been verified for distribution.
