# Third-party notices

NoMark calls the original cleaning functions directly and runs selected modules in the browser. It is an independent interface for making the upstream tool easier to use.

| Component | Purpose | License / source |
| --- | --- | --- |
| watermarks-remover | Python Unicode and metadata cleaners | [MIT](watermarks-remover/LICENSE), [source](https://github.com/guillaumemeyer/watermarks-remover), pinned commit `5c180932a00c793261177f79aee21db8929f3fe2` |
| Alpine.js CSP | Browser interface | [MIT notice](static/vendor/ALPINE-LICENSE.txt) |
| Vue reactivity/shared | Included in Alpine | [Notices](static/notices.txt) |
| Pyodide 314.0.7 | Local Python WebAssembly runtime | [MPL-2.0 notice](static/vendor/pyodide/314.0.7/LICENSE.txt), [source](https://github.com/pyodide/pyodide/tree/314.0.7) |
| CPython in Pyodide | Python standard library and runtime | [Python notices](static/vendor/pyodide/314.0.7/PYTHON-LICENSE.txt) |

The complete browser notices are served at `/static/notices.txt` and regenerated by `npm run vendor`. Required modules and the upstream license are included in the browser engine archive. Pyodide is distributed without runtime modifications; the notice links its source.

The Docker image installs FastAPI/Python dependencies and Debian packages including ExifTool, qpdf, and Ghostscript. These have their own licenses, shipped notices, and source-availability terms. The browser notice file is not an inventory of every package in the container. Review the exact built image and its `/usr/share/doc/` package notices before redistributing it.

Brand assets outline the wordmark selected for NoMark; no font binary is bundled with the logo. Runtime body text uses fonts available on the user's system.

## Optional NMT service (0.1.0-alpha.5)

Helsinki-NLP OPUS-MT en-id and id-en model cards declare Apache-2.0. Immutable source revisions and file SHA-256 values are in `nmt-service/models.lock.json`; license terms are in `nmt-service/LICENSE.models`. Converted model/tokenizer checksums are generated inside the NMT image. CTranslate2 and Transformers dependencies retain their own distribution licenses. NMT dependencies and models are not bundled into the browser engine or the main application image.
